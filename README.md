# Farm Zone — прототип Telegram Mini App

Интерактивный дизайн-прототип по двум предоставленным изображениям. Основная иллюстрация и элементы управления используются в исходном качестве. Верхняя панель заменена изображением из второго референса. Координаты интерфейса заданы на исходном холсте 768 × 1376 и масштабируются целиком, без изменения пропорций.

## Запуск

Самый простой способ: открыть соседний файл **Farm Zone — открыть игру.html** двойным щелчком. Он содержит весь интерфейс, изображения и игровую логику и работает без интернета и установки программ. Его прогресс сохраняется отдельно от серверного предпросмотра. Повторная сборка этого файла: `node build-standalone.mjs`.

Для разработки и проверки интеграции с Telegram:

Нужен Node.js 22 или новее. Дополнительные зависимости не требуются.

```text
npm start
```

Открыть `http://127.0.0.1:4173`. Статические файлы в `dist/` можно разместить на HTTPS-хостинге и указать адрес в BotFather для тестирования в Telegram.

```text
npm test
```

## Реализовано

- Три готовых растения, молодой росток, свободная и закрытая грядки. Демонстрационный профиль уровня 5: 1240 монет и 45 CR, как на втором референсе.
- Восемь сортов с различными временем, урожайностью, расходом воды и ценой.
- Многолетние растения, посадка, рост, сбор, общий склад, продажа, один заказ.
- Резервуар, восстановление воды, бесплатный колодец, остановка полива отдельных грядок.
- Улучшения урожайности, вместимости, воды, капельного полива и автосбора.
- Расширение шестой грядки и открываемая теплица с тремя посадочными местами.
- Коллекция, задания, опыт, уровни и однократные награды.
- Локальное сохранение, расчёт офлайн-прогресса, учёт вместимости и воды.
- Демонстрационная добровольная реклама с таймером и наградой в виде воды.
- Интерфейс Telegram: ready/expand, безопасные отступы, кнопка возврата, виброотклик при поддержке клиента.
- Клавиатурное управление, фокус в диалогах и режим уменьшенной анимации.

## Границы прототипа

Сцена использует готовую иллюстрацию из референса с интерактивными зонами и динамическими слоями. Исходных раздельных изображений растений и фона не предоставлено: это не полностью послойная игровая сцена, и вся нарисованная листва/плоды не могут независимо анимироваться. После действий состояние показывается отдельными метками и визуальными слоями. Для следующей версии нужны отдельные спрайты стадий, чистый фон и исходные элементы интерфейса.

Друзья и соседский сад — локальная демонстрация. Рекламная сеть не подключена. CR — демонстрационный баланс, без платежей и вывода. Прогресс хранится в браузере на устройстве; серверной проверки пользователя и экономики нет. До реального запуска необходимо добавить серверную проверку Telegram initData, хранение прогресса и проверку наград на сервере.

Внешняя публикация не выполнена: автоматическая проверка отклонила передачу файлов в Sites без явного разрешения пользователя. Локальная версия завершена; в `.openai/hosting.json` сохранён идентификатор созданного пустого приватного проекта для возможного продолжения публикации после разрешения.

## Устройство

`dist/game.js` — независимые игровые правила и симуляция времени; `dist/app.js` — интерфейс и интеграция Telegram; `dist/styles.css` — координаты референса и окна. Игровой цикл не использует постоянную отрисовку каждого кадра: состояние обновляется раз в секунду и после действий. Анимации выполняются средствами CSS, а при скрытой вкладке обновления останавливаются.
